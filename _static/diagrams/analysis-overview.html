Possible analysis algorithms

Program in, actionable feedback out

The agent submits a kernel and the parameters or inputs a check needs. Numerical comparisons identify mismatched outputs; synchronization and race diagnostics identify source operations and the ordering problems between them.

Understand the candidate's failure

The agent inspects numerical differences or reported source operations and ordering relationships to investigate the failure. Each result states the inputs or assumptions it covers.

Validate numerical behavior on CPU

In: kernel, concrete inputs, and independent reference output. Out: mismatched output name, logical index, actual value, and expected value. The agent can reproduce numerical errors and check changes without a GPU.

Explain a failed synchronization protocol

In: participants and synchronization operations. Out: a possible execution order leading to deadlock or a protocol error, with the barrier phases and source locations involved.

Identify conflicting memory accesses

In: memory accesses and their ordering. Out: conflicting source locations, overlapping bytes, and a missing happens-before relation between the accesses.

Give analyses a common program model

The compiler representation exposes thread roles, memory layouts, and synchronization semantics. Source locations connect each finding to the code the agent can inspect.
