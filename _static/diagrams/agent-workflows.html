Compose a workflow with a harness

Each workflow coordinates an optimization search. Its agents use the same compiler harness to find knowledge, implement candidates, and obtain correctness and performance feedback.

Fixed Pipeline

Research draws on the knowledge base; writing uses the compiler and correctness checks. Profiling a passing candidate supplies evidence for the next optimization direction.

Goal Mode

The goal keeps an objective active across turns. The agent chooses which harness tools to use next and checks progress against the task's correctness and performance requirements.

Flame Chase

Two agents take turns in fresh sessions, each reconsidering the work left by the other. The task and files in the repository carry the search forward within a shared run budget.

Supply capabilities to each workflow

Each workflow's agents call the compiler harness and use its feedback to guide their experiments. Saved candidates and results let the work continue across stages or turns.
