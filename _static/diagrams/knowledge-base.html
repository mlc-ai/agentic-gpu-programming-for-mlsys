Find knowledge for an optimization

The agent retrieves existing implementations and hardware specifications. Together they provide optimization ideas and the conditions needed to apply them.

Choose and adapt a strategy

The agent connects a problem in its current kernel to a mechanism in the knowledge base, checks where that mechanism applies, and adapts it to the task.

Learn from complete implementations

Ported implementations and kernels developed by agents show how algorithms, layouts, and schedules fit together. A reference can supply a matrix decomposition or a cache policy that the agent adapts to another operator.

Find mechanisms and their conditions

Hardware manuals and ISA documentation describe instructions, memory behavior, cache controls, and synchronization. The agent can find a mechanism for a bottleneck and check its requirements before using it.
